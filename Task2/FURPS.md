| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| F   | Функциональные (Functionality)     |              |
| F1  | На сайте клиент видит список доступных депозитов с актуальными ставками  |              |
| F2  | Клиент оставляет заявку на депозит с указанием телефона и ФИО |  |
| F3  | Менеджер кол-центра получает заявку и обрабатывает её | |
| F4  | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки | |
| F5  | Для открытия депозита клиент указывает счет и сумму |  |
| F6  | Клиент подтверждает открытие через СМС | Функционал СМС требует доработки, можно реализовать силами команды банка |
| U   | Удобство использования (Usability) |              |
| U1  | Должен использоваться дизайн банка: привычные цвета и брендированные элементы |              |
| R   | Надёжность (Reliability)           |              |
| R1  | Сервисы АБС должны работать 24/7 и быть доступны в 99,9% случаев |              |
| R2  | При сбое в ЦОД сервисы интернет-банка должны быть доступны и выдерживать требуемую нагрузку |  |
| P   | Производительность (Performance)   |              |
| P1  | Отклик должен быть максимально быстрый, занимать миллисекунды  | Сейчас некоторые справочные данные загружаются больше секунды |
| P2  | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД | АБС может масштабироваться только вертикально из-за БД |
| S   | Поддерживаемость (Supportability)  |              |
| S1  | Языки программирования и технологии должны быть известны сотрудникам | |
| +R  | + Ограничения (Restrictions)       |              |
| +R1 | Как можно больше использовать технологии, которые есть в банке |              |
| +R2 | Новые технологии должны быть совместимы с существующими |              |
| +R3 | Для очередей сообщений использовать Kafka | Текущая версия несовместима |
| +R4 | Возможен перевод интернет-банка на микросервисную архитектуру | Пока только для депозитов |
| +R5 | Шифрование трафика сайта и интернет-банка | |
| +R6 | Возможен перенос учета ставок по депозитам в АБС | Возможность импорта данных из xls файлов |
| +R7 | Избегать прямой работы интернет-банка с API АБС | БД перегружена |
